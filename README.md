# Bakery Route Planner

Delivery route planner for bakeries.

## Features

- Leaflet map of delivery stops
- Route organisation

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Leaflet

## Getting Started

```bash
git clone https://github.com/ghostland-dev/boulanger-tournee-planner.git
cd boulanger-tournee-planner
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
